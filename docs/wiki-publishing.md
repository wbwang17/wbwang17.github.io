# Wiki 帖子的首次发布时间

在帖子顶部的 YAML 元数据中，用 `date` 记录写作日期，用 `published_at` 单独记录首次公开发布的时间。例如：

```yaml
date: 2026-08-20
published_at: "2026-08-27T09:00:00+08:00"
lang: zh
category: research-tips
status: published
```

- `published_at` 使用带时区的完整时间，并加引号；北京时间的时区为 `+08:00`。
- 首次发布后 72 小时内，Wiki 列表的标题后显示轻微飘动的 `NEW` 标记。到期自动隐藏，无需重新生成网站；已打开页面也会更新。
- 只有 `status: published` 且语言、分类匹配的帖子才会出现在对应列表中。
- 修改正文、标题或分类时，不要重设 `published_at`，否则会重新计算上新时间。
- 未填写、格式错误或时间尚未到达时，不显示标记；不会用写作日期或网站构建时间代替首次发布时间。
- 中英文列表共用 `_includes/wiki-entry.html`；英文帖子同样填写该字段即可。当前论文写作和科研经验列表已接入。
- 后续新增其他分类的动态帖子列表时，在循环中使用 `{% include wiki-entry.html note=note %}`，即可复用相同效果。
- 标记根据访客设备时间判断；禁用 JavaScript 时不显示，设置“减少动态效果”时显示静态标记。

现有两篇笔记只提供了发布日期，因此分别按 2026-08-23 和 2026-08-27 的北京时间零点补录。以后首次发布时请填写实际时间；这不是自动读取 Git 提交或部署时间。
